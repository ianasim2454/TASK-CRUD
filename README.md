# TASK-CRUD
## About Project
### This is a CRUD project. This is done with the entire Laravel 11. Multi-authentication is done here using the Breeze Package. Category and Product CRUD operations have been performed on the Admin site. Admin template has been mastering. The forms are validated. The status of the product can be active or inactive.

# Setup Instruction: If there is no SQL file
1. First, clone the repository file.
2. composer update.
3. Create a database.
4. php artisan migrate.
5. php artisan serve.

# Setup Instruction: If there is a SQL file
1. First, clone the repository file.
2. composer update.
3. Import the SQL file into the database.
4. php artisan serve.
